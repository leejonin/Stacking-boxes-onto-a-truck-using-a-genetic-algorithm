## 목적·수정 전후

기존에는 생성 상한만 제거되어 기본 입력 18개를 모두 실으면 100세대에서 종료했다. 사용자 브라우저 지적을 반영해 자동 공급을 기본으로 하고 실제 공급·진화가 계속되도록 수정했다.

자동 공급을 기본 선택으로 설정하고 18/18개 표시를 실제 상차 개수로 변경했다. 고정 개수 입력은 수동 실험 모드에만 표시한다. 과거 선택은 당시 상자·고정 좌표 스냅샷으로 재생하며 점수 추세는 동일 입력 회차 안에서 비교한다.

## 구현과 검증

실제 코드·입출력·호출 흐름은 해당 ID 상세 문서의 최신 코드에 기록했다. 새 AutomaticSupply의 expand(best,truck)는 실제 배치에 최소 규격 후보를 추가할 수 있으면 목록을 늘린다. 공급 묶음 크기를 총량 상한으로 사용하지 않는다. Worker는 마지막 세대를 보낸 다음 새 입력으로 진화를 이어간다.

테스트 23개 통과, TypeScript·Vite 빌드 통과. tests/supply.test.ts에서 18개 이후 6회 공급으로 66개까지 ID·seed를 보존하고, 실제 Worker가 완료 대신 다음 공급 회차로 진행함을 확인했다. UI 직접 조작은 미확인이다. 관련 미해결 기술 문제는 기존 Scene problem에 유지하며 이 변경에서 추가로 확인된 미해결 문제 없음.
