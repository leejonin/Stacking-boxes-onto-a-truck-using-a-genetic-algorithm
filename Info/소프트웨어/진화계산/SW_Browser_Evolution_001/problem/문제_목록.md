## SW_Browser_Evolution_Bug_001 — 최초 입력 소진 후 자동 공급 없이 종료

- 상태: 해결. 코드·Worker 회귀 검증 및 브라우저 실제 자동 공급 2회차·21개 상차 표시 확인 완료.
- 발생 기능·근거: 진화 Worker의 `engine.generation>=engine.settings.generations` 분기가 항상 완료로 종료했다. UI에는 18/18개가 표시되어 총량 제한처럼 보였으며 실제로 다음 상자 공급도 없었다.
- 원인: 숫자 입력 상한 제거와 지속 공급을 서로 다른 문제로 구분하지 않아 기본 입력 목록은 유한한 채 남았음.
- 수정: 자동 공급 모드에서 해당 분기를 다음 입력 생성·새 Engine 시작으로 변경. 최소 규격을 넣을 추가 공간·경로가 없을 때만 현재 배치의 상차 불가로 종료. 사용자가 정지할 수도 있음.
- 영향 범위: EvolutionView는 실제 개수만 표시하고 기본 자동 공급을 활성화했다. 과거 3D는 당시 입력 스냅샷으로 보존.
- 검증: tests/supply.test.ts의 실제 Worker 자동 회차 전환 및 18→66개 지속 공급·고유 ID·재현성 확인. 전체 테스트 23개·빌드 성공.
- 사용 환경: Info/기술환경.md.
- 관련 day: 프로젝트 루트 기준 `Info/소프트웨어/진화화면/SW_Browser_EvolutionView_001/day/2026-11-16_131321_SW_Browser_EvolutionView_001_18개기본종료제거.md` 및 Evolution의 같은 시각 day.

## SW_Browser_Evolution_Bug_002 — 공급 경계에서 집단·부모 단절 및 점수 하락

- 최초 확인·수정: 2026-11-16 19:23:49 (KST)
- 상태: 코드 수정·회귀 테스트 및 기본 Worker 실행 검증 완료. 새 브라우저 직접 조작 미확인.
- 원인: 새 입력으로 Engine 집단 초기화, 상차 순서 재무작위화, 이전 부모 ID 미계승 및 입력 비율 분모 변화. 입구 막힘을 전체 공급 종료로 간주하는 별도 조기 종료 조건도 존재했다.
- 수정: Engine.inherit로 전체 집단·좌표·순서·실제 부모와 최초 점수 분모 계승. 공급 종료는 남은 부피 1000cm³ 미만으로 제한. 세대·후보·주기 안내와 전체 실행 그래프 적용.
- 검증: 25개 테스트 통과. 기본 Worker의 100→101세대 점수 100.34→120.14, 최대 적재 18→24, 102세대 최대 25. 모든 101세대 부모가 100세대 실제 ID에 연결됨. 테스트에서 18개 초과 적재 확인.
- 한계: 실행 예산 내 최적 배치 도달은 보장하지 않음. 평가식은 최초 입력 대비 보상이며 퍼센트 상한이 아니므로 100점 초과 가능.
- 계획: `Info/plan/2026-11-16/192349_자동공급세대계승수정_plan.md`. 관련 기능 day는 같은 시각 공급경계계승 기록.
