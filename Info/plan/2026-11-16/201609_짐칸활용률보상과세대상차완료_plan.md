## 계획과 실제 구현

1. Weights.fill(선택 입력, 생략 시50)을 추가하고 기본50점으로 설정한다. loadingFitness에 fill×utilization을 더한다. utilization은 실제 적재 부피/짐칸 부피이며80%=40점,90%=45점,100%=50점이다. 기존 개수·부피 보상100, 공간 집중도20, 재이동10, 중량1은 유지한다. 음수·비유한 가중치는 기존 설정 검사에서 거부한다. 사용자 지정0점은 허용한다.
2. 평가 가중치에 짐칸 적재율 보상(100% 기준) 입력을 추가하고 적용 버튼으로 현재 집단의 점수를 다시 계산한다. 배치 좌표와 실제 이동 비용은 바꾸지 않는다. 완료 적재율(%)은 별도 입력이다.
3. Worker는 추가 공간 없음과 전체 실행 완료를 구별한다. 매 세대 개체 중 하나라도 최소 생성 상자를 추가할 공간이 없으면 Generation.capacityReached=true와 generationCapacity 알림을 보내고 다음 세대로 계속한다. 트리의 해당 행에는 상차 완료를 표시한다. 남은 실제 부피0%=활용100%이면 기본 전체 완료 조건에 도달한다. 기존 사용자 지정 완료 적재율(기본100%)도 유지하므로 사용자가90%로 바꾸면90% 이상에서 전체 완료한다.
4. 공간 없음만으로 전체 완료했던 이전 동작을 이번 명시적 답변으로 대체한다. 기존 ID 유지·추가 공급·재배치 비용·겹침 금지는 유지한다. 자동 공급의 회차 예산과 수동 실험의 총 세대 예산도 유지한다.
