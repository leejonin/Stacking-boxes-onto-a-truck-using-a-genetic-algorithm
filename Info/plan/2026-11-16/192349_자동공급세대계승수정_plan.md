## 구현 계획과 원인

기존 코드에서 공급 시 새 집단을 초기화하고 상차 순서를 무작위화하여 부모 연결·엘리트가 끊기는 것을 확인했다. 입력 개수·부피가 커지면서 기존 배치의 정규화 점수가 낮아졌다. 현재 입구 막힘만으로 전체 공급을 종료하는 검사도 재배치 가능성을 제외했다.

1. 이전 집단의 좌표·상차 순서와 실제 부모 ID를 전부 계승하고 신규 상자 ID는 순서 뒤에 추가한다. 새 상자는 미배치로 시작하여 후손의 좌표 복구·변이로 적재한다.
2. 자동 공급의 적재량 보상 분모를 최초 입력 개수·부피에 고정한다. 가중치 100·10·1·공간 20 및 보상·감점 목적은 유지한다.
3. 최소 생성 부피 1000cm³도 남지 않은 경우만 자동 용량 종료한다. 재배치를 탐색할 수 있으므로 현재 한 배치의 입구 막힘으로 종료하지 않는다. 물리적 공간을 채울 때까지의 성공·최적성·종료 시간은 보장하지 않는다. 사용자 정지는 유지한다.
4. 전체 실행 점수 추세와 누적 세대·공급 후보 개수·기본 100세대마다 8개 공급 안내를 표시한다.
5. 100→101 실제 부모·점수 보존과 18개 초과 적재, 입구 막힘에 따른 조기 종료 방지를 회귀 검사한다. 기본 50개 집단 실제 Worker도 110세대까지 검사한다. 빌드 후 기존 Public main/gh-pages에 반영한다.
